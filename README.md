# Catalog-RSS-Feed

YML-фиды каталога ТД РУССтанкоСбыт (бренд РСС) и фотографии товаров для этих фидов. Репозиторий публичный: секретов, ключей и персональных данных здесь быть не должно.

## Статус
Нет данных об этапе (в работе / в проде / архив) и о том, кто ведёт репозиторий; в реестре агентов хаба для него отдельной записи нет. Составлено 2026-11-24 по `git ls-files` (агент kb-rss, задача pm-11220845-index). Последний коммит в репозитории: 2026-11-05, «Секреты: файлы с ключами убраны из индекса, добавлен .gitignore-блок защиты».

## Что внутри (карта в три строки)
- `YML-*.yml`, `YML-MashPort.xml`, `PromIndex-500-*.yml` — фиды каталога (число предложений и даты — в `КАРТА-ПРОЕКТА.md`).
- `Foto-PromPortal/` — 406 фото с латинскими именами файлов и таблица соответствия `_mapping.csv`.
- `Foto-RSS/` — 714 фото с кириллическими именами; `Zaglushka.jpg` — фото-заглушка в корне.
Полная карта: `КАРТА-ПРОЕКТА.md`; задача → файл: `INDEX.md`; файла `CLAUDE.md` нет.

## Как запустить локально
Нет данных: в репозитории нет скриптов, тестов и `requirements.txt`; это набор файлов. Чем и как фиды загружаются на площадки, из репозитория не видно.

## Как это выкладывается
Нет данных. Фото в фидах указаны ссылками `raw.githubusercontent.com` на файлы этого репозитория и репозитория Foto-RSS. Публикация фидов, домены и хостинг — решает только владелец; прод-деплой — только с «да» владельца.

## Связи
- Фото в фидах ссылаются на репозитории `Catalog-RSS-Feed` (корень и `Foto-PromPortal/`) и `Foto-RSS`.
- Коды товаров в фиде вида `RSS-NNNNN` совпадают по формату с кодами базы знаний РСС (репозиторий rss-razrabotki); совпадение значений фида с каталогом базы знаний не проверялось: Нет данных.

Секретов, ключей, значений переменных. Телефон и e-mail компании внутри YML-файлов есть как поля фида (в этих документах не повторяются).
